## Материалы

content/pages/*.json — разметка страниц и стили из согласованных HTML-макетов. TemplatePage выводит их на сервере; SiteBehavior отвечает за меню, фильтр, форму и анимацию прокрутки. Оригинальные скрипты прототипа не исполняются.

content/articles/*.mdx — один файл на статью. Между разделителями --- находятся метаданные в JSON (совместимом с YAML), далее HTML-содержимое статьи. Поля: slug, title, summary, lead, category, minutes, date, status, featured, pinned, checklist, cta. Содержимое локальное и доверенное; произвольный JSX не исполняется. status=published создаёт отдельную страницу; status=soon показывает карточку подготовки. После добавления материала нужна пересборка.

public/images — оригинальные логотипы и изображения новых макетов, включая PDF-пример отчёта. Manrope хранится локально в app/fonts вместе с лицензией OFL.
