# Лэмп Лигал

Сайт-визитка юридической компании с главной страницей и макетом блога.

## Запуск

Установите зависимости командой npm install, затем запустите npm run dev.
Откройте http://localhost:3000.

## Страницы

- / — главная страница.
- /blog — макет блога.
- /hero-options — три варианта первого экрана для выбора.
- /privacy — временная страница политики обработки персональных данных.

## Перед публикацией

- Окно заявки пока демонстрационное: введённые данные не отправляются. После выбора способа доставки нужно подключить отправку формы.
- Замените содержимое /privacy на согласованный текст политики.
- Материалы в lib/posts.ts — демонстрационные темы. После подготовки текстов можно добавить страницы статей и ссылки из карточек.
- Фотографии public/images/about-generated.png и public/images/approach-generated.png созданы как временные визуалы и могут быть заменены фотографиями заказчика.
- Фирменные логотипы находятся в public/images/logoBlack.png и public/images/logoWhite.png.

## Проверка

Запустите npm run lint и npm run build.
